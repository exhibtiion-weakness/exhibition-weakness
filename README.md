# QR → カメラ + 半透明スクロールテキスト(作品ごとの解説つき)

作品ごとのQRを読み取ると、カメラ映像の上に、その作品の解説が半透明でスクロールできる形で重なります。

## ファイル
- `index.html` … ページ本体。URLの `?w=番号` で表示する作品を切り替える
- `works.json` … 作品の番号・名前・解説文(ここを編集して文章を直す)
- `make_qr.py` … 全作品ぶんのQR画像(`qr-1.png` …)を作り、読み取りテストまで行う
- `qr-1.png` 〜 `qr-6.png` … 作成済みのQR(`https://tanaka0137.github.io/weakness/?w=番号`)

## 公開(GitHub Pages)
`index.html` と `works.json` をリポジトリのルートに置いて push。数分後に
`https://tanaka0137.github.io/weakness/?w=1` などで開けます。

## 文章を直す・作品を足す
1. `works.json` を編集(`id` / `title` / `name` / `body`)。`body` は段落ごとに1項目
2. push する。**QRの作り直しは不要**(文章はQRに入っていないため)
3. 作品を足したときだけ `python make_qr.py https://tanaka0137.github.io/weakness/` を実行し、増えた分のQRを印刷

## 注意
- 作品の `id` は途中で変えない(印刷済みQRが別の作品を指してしまう)
- `index.html` をダブルクリックで直接開くと、`works.json` を読めず解説が出ない。確認は公開URLで行う
- `works.json` の書き方を間違える(カンマ抜けなど)と全作品の解説が出なくなる。直したあと、公開URLで1つ開いて確認する
